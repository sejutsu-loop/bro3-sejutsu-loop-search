1. カードファイルからコピーした内容を貼り付け

カードファイル画面で「小15枚表示」または「小60枚表示」にして、対象カードをまとめてコピーし、そのまま貼り付けてください。
カード名・No・コスト・スキル名・超覇補正・明鏡/明鑑/錬鏡・療覚醒 を自動解析します。カード境界はNo行で判定するため「デッキコスト不足」のカードも個別に解析します。副将の明鏡/錬鏡はスキル名から対象レアリティを自動判別し、解析後に副将スロットごとに「効果なし / 明鏡効果 / 錬鏡効果（条件一致）」を個別選択できます。SLの2副将もそれぞれ独立して設定できます。スキル回復以外のスキルも貼り付けたままで構いません。

2. 探索対象カードを選択

解析したカードは初期状態ですべて探索対象です。施術ループに含めたくないカードは、左端のチェックを外してください。特に「龍肝の湯薬」を持つ左慈は、チェックされている場合は必須候補として探索します。副将の明鏡/錬鏡はスキル名から R / SR / UR / L / SL を自動判別します。明鏡は各副将スロットごとに「効果なし / 明鏡効果」、錬鏡は各副将スロットごとに「効果なし / 明鏡相当効果 / 錬鏡効果（勢力等の条件一致）」から選択できます。SLの2副将は副将1・副将2を独立して設定し、初期値はそれぞれ明鏡なら明鏡効果、錬鏡なら条件一致の錬鏡効果です。表示する％と短縮分数にはスキルLVを反映します。龍肝の湯薬はゲーム仕様に合わせ、主将鏡・副将鏡・錬鏡によるコピー効果を一切加算しません。霊丹3種は待機中対象の自己除外型として扱います。療覚醒は第1スキル本体だけに作用し、LV1=3.0倍、LV2=3.1倍、…、LV9=3.8倍、LV10=4.0倍として反映します。主将明鏡・副将明鏡・錬鏡は療覚醒前の第1スキル効果をコピーします。
